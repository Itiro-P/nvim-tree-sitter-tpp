# nvim-tree-sitter-tpp

---

This plugin enables syntax highlighting on the `Tpp` programming language for Neovim

## Setup

You need `nvim-tree-sitter` to be already installed. With `Lazy.nvim`, load the plugin at your `lua/plugins` directory and it should load when you start Neovim:
```lua
return {
  "Itiro-P/nvim-tree-sitter-tpp",
  opts = {},
}
```

# nvim-tree-sitter-tpp
---

[Português](#português) | [English](#english)

---

## Português

Este plugin habilita o realce de sintaxe (syntax highlighting) para a linguagem de programação `Tpp` no Neovim

### Configuração
Você precisa ter o `nvim-tree-sitter` já instalado. Com o `Lazy.nvim`, carregue o plugin no diretório `lua/plugins` e ele deverá carregar quando você iniciar o Neovim:
```lua
return {
  "Itiro-P/nvim-tree-sitter-tpp",
  opts = {},
}
```
